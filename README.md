# Sistema Básico de Gestión de Pedidos e Inventario (Reto 2)

Este proyecto corresponde a la práctica del **Tema 5: Arreglos y Tipos Abstractos de Datos (Parte 1)**. Implementa un sistema modular en Python utilizando listas (arreglos unidimensionales estructurados) para administrar registros de inventario y pedidos de forma interactiva.

## Funcionalidades Implementadas
- **Inventario:** Registro, visualización, edición y eliminación de productos y stock.
- **Pedidos:** Gestión completa de solicitudes de clientes (crear, listar, modificar y borrar pedidos).
- **Modularidad:** Código organizado mediante funciones y procedimientos específicos para cada acción.
